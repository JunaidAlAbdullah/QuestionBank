Uploading rules

Question has 2 pages?

Select both images together in the file picker (hold Ctrl while clicking, or Shift for a range). Keep the same title, and just add "Part 1" / "Part 2" so it stays one listing.

Example:
Title: Operating System Midterm — Part 1
Title: Operating System Midterm — Part 2
(or upload both images in a single entry — either works, just stay consistent)

Multiple separate quizzes/exams?

If you have "Quiz 1" and "Quiz 2" from different dates, these are different questions — upload them as two separate entries, not as pages of one upload.

Example:
Title: Data Structures — Quiz 1 Question
Title: Data Structures — Quiz 2 Question

More than 2 pages?

Please combine all pages into a single PDF instead of uploading many images (max 10MB total). A free, easy tool for this:

Convert JPG to PDF — iLovePDF ↗

A few more tips

  • Take photos in good lighting, straight-on (not at an angle) so text is easy to read.
  • Crop out anything outside the question paper before uploading.
  • Don't re-upload a question that's already on Question Bank — search first.
  • Only PDF, PNG, JPG, or WEBP files are accepted, 10MB max per file.
